Упражнение 1. Карточка приветствия
Создайте компонент GreetingCard с пропсами: name (строка, обязателен), age (число, по умолчанию 18) и role (строка, по умолчанию «Студент»). 
Выведите на странице три карточки через v-for по массиву людей. Для одного человека не передавайте age и role, чтобы увидеть значения по умолчанию.


Упражнение 2. Счётчик с событием
Создайте компонент CounterButton с пропсами label и step (по умолчанию 1). 
Он хранит свой счётчик и по клику увеличивает его на step. При каждом изменении он отправляет событие change с новым значением. 
В родителе подключите два счётчика («Яблоки» и «Груши» с шагом 5) и под ними выведите сумму обоих через computed.


Упражнение 3. Блок со слотами
Создайте компонент InfoBox со слотами: header (по умолчанию «Информация»), слот по умолчанию для содержимого и footer, 
который показывается только когда передан. Используйте компонент три раза: без заголовка и подвала, только с заголовком, 
с заголовком и подвалом.


Упражнение 4. Список задач из компонентов
Сделайте список задач. Компонент TodoItem получает пропс todo (id, title, done) и отправляет события toggle и remove. 
В App хранится массив задач (через useLocalStorage), есть форма добавления, счётчик «Осталось: N» через computed
и кнопка «Очистить выполненные», которая видна только если есть выполненные задачи.
